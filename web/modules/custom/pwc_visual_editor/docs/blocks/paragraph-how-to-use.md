# Paragraph Block: How To Use

This guide explains how to use the Paragraph block in the PWC Visual Editor.

## What the Paragraph block does

The Paragraph block lets you write and style longer text content.

You can:

- Type text directly in the canvas
- Create multiple paragraphs in one block
- Control typography (size, weight, line height, alignment, color)
- Control spacing (paragraph gap, margin, padding)
- Add custom CSS classes

## Add a Paragraph block

1. Open the block library.
2. Select `Paragraph`.
3. A new block is inserted with starter text: `Enter your text here...`.

## Write and edit text

1. Click inside the paragraph block.
2. Type your content.
3. Press `Enter` once for a line break (`<br>`).
4. Press `Enter` twice to start a new paragraph (`<p>`).

The editor keeps everything inside one Paragraph block, even when you have multiple paragraphs.

## Indent and outdent paragraphs

Inside the Paragraph block:

- Press `Tab` to indent the current paragraph.
- Press `Shift + Tab` to outdent the current paragraph.

Tip:

- Indent can go up to 4 levels.

## Paste text from other sources

When you paste content:

- Extra formatting is removed.
- Clean paragraph structure is kept.
- Line breaks are preserved.

This helps avoid messy HTML from Word, Google Docs, or web pages.

## Style options

Select the Paragraph block, then use the settings panel:

- `Font Size`
- `Font Weight`
- `Line Height`
- `Alignment`
- `Text Color`
- `Paragraph Gap` (space between `<p>` tags)
- `Margin`
- `Padding`
- `Custom Classes`

Default paragraph gap is `16px` (`pwc-space-y-4`).

## Common workflow

1. Add Paragraph block.
2. Write or paste content.
3. Split into paragraphs with double `Enter`.
4. Adjust typography and spacing.
5. Add custom classes only if needed.

## Tips

- Keep paragraphs short for better readability.
- Use `Paragraph Gap` before adding manual line breaks everywhere.
- Use `Custom Classes` for project-specific styles only.
