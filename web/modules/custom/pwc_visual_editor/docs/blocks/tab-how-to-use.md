# Tab Block: How To Use

This guide explains how to use the Tab block in the PWC Visual Editor.

## What the Tab block does

The Tab block creates a tabbed content area where each tab has its own content panel.

By default, a new Tab block starts with:

- `Tab 1`
- `Tab 2`
- `Tab 3`

Each tab panel can contain any inner blocks (Heading, Paragraph, Image, Button, etc.).

## Add a Tab block

1. Open the block library.
2. Select `Tab`.
3. The block is inserted with default tabs and empty tab panels.

When a panel has no content, the editor shows `Drop blocks here`.

## Add content to a tab

There are two easy ways:

1. Click the `+` button inside the tab panel.
2. Drag a block from the block library and drop it into the panel.

The inserted block is saved to the currently selected tab.

## Rename, add, or remove tabs

1. Select the Tab block.
2. Open the settings panel.
3. In `Tab Items`:
- Rename tab labels.
- Add new tabs.
- Remove tabs you no longer need.

Tip: Keep tab labels short and clear for better usability.

## Change tab style

Use `Tab Style` in settings:

- `Underline`: tabs with underline style
- `Filled`: tabs with filled style

Use `Stretch Tabs` if you want tabs to fill the full row width.

## Style the content area

Use these settings to control the tab content container:

- `Content Background`
- `Margin`
- `Padding`
- `Custom Classes`

`Custom Classes` accepts space-separated class names.

## Reorder or delete the full Tab block

While editing:

- Use the drag handle on the block controls to reorder the whole Tab block.
- Use the trash icon to delete the Tab block and all nested tab content.

## Tips

- Use 3 to 6 tabs for best readability.
- Avoid very long tab titles.
- Put related content together inside each tab.
- Use `Stretch Tabs` for equal-width navigation on wide layouts.
