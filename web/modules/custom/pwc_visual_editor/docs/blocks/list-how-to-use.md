# List Block: How To Use

This guide explains how to use the List block in the PWC Visual Editor.

## What the List block does

The List block adds a text list to your page.

You can choose:

- Unordered list (bullets)
- Ordered list (numbers/letters/roman)
- Marker position (inside or outside)
- Text style, color, spacing, and custom classes

## Add a List block

1. Open the block library.
2. Select `List`.
3. A default list is added with one item.

## Write list content

1. Click inside the list.
2. Type your first item.
3. Press `Enter` to create a new list item.
4. Press `Shift + Enter` for a line break inside the same item.

## Keyboard behavior in the editor

The List block supports common list editing shortcuts:

- `Enter`: creates a new list item
- `Shift + Enter`: inserts a line break (`<br>`) inside current item
- `Tab`: indents item (creates nested list)
- `Shift + Tab`: outdents item
- `Backspace` at start of item: merges with previous item or removes empty item

## Change list type and style

In the settings panel, use:

- `List Type`: `Unordered (Bullets)` or `Ordered (Numbers)`
- `List Style`: marker format
- `Marker Position`: `Outside` or `Inside`

Examples:

- Unordered + `Disc (●)` for standard bullet lists
- Ordered + `Decimal (1, 2, 3)` for step-by-step instructions
- Ordered + `Upper Alpha (A, B, C)` for grouped sections

## Typography and layout options

Use these settings as needed:

- `Font Size`
- `Font Weight`
- `Line Height`
- `Alignment`
- `Text Color`
- `Item Gap`
- `Margin`
- `Padding`
- `Custom Classes`

## Paste behavior

When you paste text into the list:

- Formatting is removed
- Plain text is used
- Multiple pasted lines become separate list items

## Tips

- Keep each list item short when possible.
- Use nested lists (`Tab`) only when hierarchy is truly needed.
- Choose `Inside` marker position when list items are long and multi-line.
- Use `Custom Classes` only for styles not covered by built-in settings.
