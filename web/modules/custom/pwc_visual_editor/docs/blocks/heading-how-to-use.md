# Heading Block: How To Use

This guide explains how to use the Heading block inside the PWC Visual Editor.

## What the Heading block does

The Heading block adds a title text element to your page.

You can:

- Edit the text directly on the page
- Choose heading level (`H1` to `H6`)
- Change typography (size, weight, line height, alignment)
- Change text color
- Add spacing (margin and padding)
- Add custom CSS utility classes

## Add a Heading block

1. Open the block library.
2. Select `Heading`.
3. A new heading is inserted with default text `Heading`.

## Edit heading text

1. Click the heading text in the canvas.
2. Type your content directly.
3. Click outside the block when done.

Tip:

- Keep headings short and clear so page sections are easy to scan.

## Choose the heading level

1. Select the Heading block.
2. Open the settings panel.
3. Under `Heading Level`, choose `H1`, `H2`, `H3`, `H4`, `H5`, or `H6`.

Recommended usage:

- Use one `H1` per page for the main title.
- Use `H2` for major sections.
- Use `H3` to `H6` for deeper subsections.

## Style the heading

Use these settings in the panel:

- `Font Size`
- `Font Weight`
- `Line Height`
- `Alignment`
- `Text Color`

If `Font Size` or `Font Weight` is left as `Default`, the block uses automatic defaults based on heading level.

## Add spacing

Use:

- `Margin` to control outer spacing
- `Padding` to control inner spacing

This helps separate the heading from nearby blocks.

## Add custom classes

Use `Custom Classes` to add one or more space-separated class names.

Example:

`ap-typography-heading ap-text-primary-blue-04`

## Common workflow

1. Insert Heading block.
2. Type heading text.
3. Set correct heading level.
4. Adjust typography and spacing only if needed.
5. Add custom classes for project-specific styling.
